# Питонариум

Школьная интерактивная лаборатория Python. Автор проекта — Русинов Давид, ученик 11А класса.

## Запуск

1. Установите Python 3, если он ещё не установлен.
2. Откройте терминал в этой папке.
3. Выполните `python -m http.server 8000` (в Windows также можно `py -m http.server 8000`).
4. Откройте http://localhost:8000 в современном браузере.

Или запустите `Запустить.cmd`. Не открывайте index.html двойным щелчком: ES-модулям и Web Worker нужен HTTP-сервер.

## Возможности

- Шесть модулей: краткая теория, пример, пошаговая модель, две задачи и мини-тест.
- Настоящий Python через Pyodide 0.29.2 в Web Worker. Поле ввода подаёт строки в input(). Кнопка остановки завершает Worker; лимит программы — 8 секунд после загрузки среды, лимит загрузки — 120 секунд.
- Лаборатория с шестью заданиями, свободным редактором, подсветкой и предсказанием вывода. Проверки используют вывод на нескольких входных данных, значения переменных и вызовы функции; для отдельных задач проверяется использование input() или цикла через AST.
- Финальный тест из 20 вопросов. Сертификат доступен только при 11–20 верных ответах. Для сертификата берётся лучший результат; дата относится к этой попытке.
- PDF A4, альбомная ориентация, одна страница. Кириллица рисуется браузером в высоком разрешении и включается в PDF изображением (текст не выделяется). Печать доступна отдельно.
- Прогресс, ответы, код и лучший результат хранятся в localStorage на данном устройстве. Нет регистрации и сервера с персональными данными.

## Папки

`index.html` — оболочка; `css/` — адаптивные стили; `js/content.js` — весь курс и вопросы; `js/app.js` — интерфейс и проверки; `js/worker.js` — изолированный Python; `assets/` — оригинальный SVG-знак, локальный шрифт Onest и библиотека jsPDF.

## Сеть и зависимости

Интернет нужен для первого запуска Python: среда и стандартная библиотека загружаются с https://cdn.jsdelivr.net/pyodide/v0.29.2/full/. Остальной интерфейс, шрифт и PDF-библиотека локальные. Дополнительные пакеты pip не устанавливаются. Ошибки загрузки показываются в области вывода. Загрузка среды может потребовать несколько десятков мегабайт.

Pyodide: https://pyodide.org/en/0.29.2/usage/webworker.html (MPL-2.0 и лицензии включённых компонентов). jsPDF 2.5.2 — MIT, сведения о лицензии в заголовке файла. Onest — SIL Open Font License, см. assets/FONT-LICENSE.txt. Векторный символ Python и знак сайта созданы средствами SVG, без внешних изображений. Референсы использованы только как ориентир; их изображения в проект не включены.

## Ограничения

Это учебный проект: локальный прогресс и сертификат не защищены от изменения через инструменты разработчика и не являются официальным документом об образовании. Для заданий с input() ввод подготовлен заранее в поле под редактором. Пошаговое выполнение работает для учебных моделей; произвольный код запускается целиком. PDF использует растровый текст ради надёжного отображения кириллицы без удалённых шрифтов.
